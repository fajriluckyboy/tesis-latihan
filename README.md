# Tesis: Simulasi Penulisan Kolaboratif via GitHub

Repo ini adalah simulasi penulisan naskah akademik
(tesis) menggunakan Git dan GitHub sebagai alat
kolaborasi antara penulis dan pembimbing.

## Struktur Naskah

- bab-01-pendahuluan.md
- bab-02-tinjauan-pustaka.md
- bab-03-metode.md

## Alur Kerja

Setiap revisi bab dilakukan melalui branch terpisah,
diajukan sebagai Pull Request, dan direview oleh
pembimbing sebelum digabungkan ke naskah utama.
