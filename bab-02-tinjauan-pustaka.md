# Bab 2: Tinjauan Pustaka

## Version Control dalam Konteks Non-Software

Beberapa studi dan praktik komunitas menunjukkan bahwa
sistem version control seperti Git dapat diadaptasi
untuk berbagai bidang di luar pengembangan perangkat
lunak, termasuk penulisan akademik, pengelolaan data
penelitian, dan dokumentasi hukum.

## Kolaborasi Berbasis Pull Request

Pola kerja Pull Request, yang awalnya dirancang untuk
review kode program, terbukti dapat diterapkan pada
proses review naskah. Reviewer dapat memberikan
komentar pada baris teks tertentu, sehingga proses
revisi menjadi lebih terstruktur dibandingkan metode
konvensional seperti pengiriman dokumen melalui email.
