# Bab 3: Metode

## Pendekatan Simulasi

Penulisan ini menggunakan pendekatan simulasi praktik
langsung, di mana setiap tahapan alur kerja Git dan
GitHub dijalankan secara nyata pada repositori latihan,
bukan sekadar dijelaskan secara teoritis.

## Tahapan Pelaksanaan

Simulasi dilakukan melalui beberapa tahapan, yaitu:
pembuatan naskah awal, revisi melalui branch dan Pull
Request, pemberian komentar oleh pembimbing pada baris
teks tertentu, revisi lanjutan berdasarkan masukan,
hingga penandaan versi resmi melalui git tag dan
GitHub Releases.
